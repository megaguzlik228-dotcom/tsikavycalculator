# tsikavycalculator

калькулятор на маленьком трансформере, сам учится считать + - * / на целых числах от -100 до 100

внутри мини-GPT: RMSNorm, RoPE, QK-norm, SwiGLU. умножение модель считает через черновик по шагам (`23*45=` -> `23*5=115;23*40=920;115+920=1035;=1035`), остальное сразу ответом, цифры задом наперед

## запуск
```
pip install torch tqdm matplotlib
python friday_micro_math-1.py
```
на видюхе 3060 учится несколько минут, на проце будет долго

## что крутить
все настройки сверху файла:
- `OPS` какие операции
- `MAX_N` до какого числа по модулю
- `TRAIN_POOL` сколько разных примеров в обучении
- `D_MODEL, N_LAYERS, N_HEADS` размер модели
- `STEPS` сколько шагов учить

## результат (6000 шагов, 2.66М параметров)
точность на примерах которые модель не видела:

| + | - | * | / |
|---|---|---|---|
| 1.00 | 1.00 | 1.00 | 0.89 |

деление хуже всего, т.к. для него нет черновика
